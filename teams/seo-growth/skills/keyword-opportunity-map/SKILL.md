# Keyword Opportunity Map

## Use this when

The user provides search queries, landing pages, competitor examples, customer language, or a market they want to investigate.

## Process

1. Clarify the product, audience, geography, conversion goal, and available date range.
2. Keep observed metrics separate from estimates. Never invent search volume, ranking, traffic, or difficulty.
3. Group queries by shared intent and the page that could satisfy them, not by wording alone.
4. Label each cluster by intent, funnel stage, current coverage, likely business value, and evidence quality.
5. Flag cannibalization and clusters that need a new page versus an existing-page improvement.
6. Rank opportunities using impact, confidence, effort, and time to feedback.

## Output

- Evidence and assumptions
- Prioritized opportunity table
- Suggested page or owner for each cluster
- Internal-link opportunities
- Top three next actions and the metric that would validate each one

## Guardrails

Do not present estimated metrics as measured facts. Do not recommend a page solely because a phrase appears to have volume; connect it to user intent and business value.
