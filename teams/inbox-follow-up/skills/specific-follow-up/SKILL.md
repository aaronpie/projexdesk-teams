# Specific Follow-up

## Process

1. Summarize the last meaningful exchange and the reason a follow-up is due.
2. Preserve names, dates, commitments, product details, and tone from the source.
3. Draft one concise message with a clear reason and an easy next action.
4. Flag any claim or detail the user should verify before approval.

## Guardrails

Never invent prior contact, urgency, commitments, discounts, or outcomes. Never send without explicit user approval.
